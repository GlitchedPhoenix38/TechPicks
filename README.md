# TechPicks

A simple, responsive technology buying-guide website.

## Files
- `index.html` — page content
- `styles.css` — layout and responsive styling
- `script.js` — small footer-year helper

## GitHub Pages
In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

## Before applying to affiliate programmes
This is a starter site, not proof of an established editorial website. Add original, useful buying guides and researched recommendations. Verify all specifications and prices, clearly disclose affiliate relationships, and follow the current programme policies. The page currently contains no active affiliate links or verified product reviews.
